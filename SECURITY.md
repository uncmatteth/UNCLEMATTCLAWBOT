# Security Policy

## Reporting a Vulnerability
If you believe you have found a security issue, please avoid public disclosure.

Preferred:
- Use GitHub Security Advisories for private reporting (if enabled on this repo).

Fallback:
- Open a GitHub issue with minimal details and clearly mark it as "Security".

## What to Include
- A clear description of the issue and impact.
- Steps to reproduce (proof-of-concept if available).
- Affected versions or commit hash.

## Supported Versions
Only the latest release is supported with security fixes.

## Response Time
We will acknowledge reports as soon as possible and provide a remediation plan or timeline.
